Level 1 — Light 8-Bit Theming

Swap colors, fonts, and borders to 8-bit palette. Rounded corners become pixel-sharp. Monospace everywhere. Minimal structural change — same components, retro colors.

Pros

  • Lowest risk — no layout changes
  • Fast to implement
  • Easy to revert

Cons

  • Surface-level — may feel like a "skin"
  • Modern components in retro colors can clash

Level 3 — Deep RPG / JRPG

Full game immersion: scanlines, status bars (HP/GOLD/TIME), inset panels, double borders, shimmer text, RPG menu sounds metaphor. Every detail screams 8-bit RPG.

Pros

  • Maximum impact — unforgettable
  • Status bar adds fun game metaphors
  • Distinctive brand identity

Cons

  • Most work — many new UI primitives
  • Scanlines + effects need CSS care
  • Game metaphors (HP/GOLD) may confuse non-gamers
